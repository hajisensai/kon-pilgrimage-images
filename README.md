# K-ON! 聖地巡礼 截图镜像

本仓库只做一件事：为一张 [K-ON! 巡礼 Google My Maps 地图](https://www.google.com/mymaps)
提供**不做 Referer 校验的图片直链**。Google My Maps 的信息弹窗无法加载原站图片
（原站有防盗链），也无法显示 KMZ 包内嵌的图片，故在此镜像。

## 文件命名

`<bangumi_subject_id>_<anitabi_point_id>.jpg`，例如 `1424_25idmdc.jpg`
（1424 = けいおん！，3774 = けいおん！！，12426 = 映画 けいおん！）。

## `print_frames/`

现场手持对照用的**动画原帧截图**（46 张，来自 TV 动画本篇，非 Anitabi 投稿），
对应一张「已打印照片」版的 Google My Maps 地图，弹窗里显示的就是这些画面。
`print_frames/_index.csv` 记录每张图对应的点位名、坐标、季/话与 Anitabi 链接。

这部分画面版权归 **京都アニメーション / かきふらい・芳文社**，仅作个人巡礼对照之用，
非商业用途。版权方要求撤下时删除本目录或整个仓库即可，地图的点位与地址数据不受影响。
