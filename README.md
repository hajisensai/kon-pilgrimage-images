# K-ON! 聖地巡礼 截图镜像

本仓库只做一件事：为一张 [K-ON! 巡礼 Google My Maps 地图](https://www.google.com/mymaps)
提供**不做 Referer 校验的图片直链**。Google My Maps 的信息弹窗无法加载原站图片
（原站有防盗链），也无法显示 KMZ 包内嵌的图片，故在此镜像。
